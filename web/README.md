# Silo web

React 19 · TanStack Router (file-based) · TanStack Query · Tailwind v4 + shadcn/ui.

```bash
npm run dev        # http://localhost:3000 (needs the Go API on :8080)
npm run lint       # includes architecture boundary rules
npm run typecheck
npm run format
```

## Data in development

Vite proxies `/api` to the Go API on `http://localhost:8080`, so start the backend before `npm run dev`.

`src/app/route-tree.gen.ts` is generated by the TanStack Router Vite plugin from `src/routes/` — don't edit it by hand.

## API types (when the backend publishes a spec)

The Go handlers carry `swag` annotations. Once `swag init` writes `api/docs/swagger.json`:

```bash
npm run api:types  # → src/lib/api-schema.d.ts
```

Then replace the hand-written `features/*/types.ts` with the generated types.

## Structure

`app/` (entry, providers, router) → `routes/` (file-based pages; `-components/` are route-private) →
`features/` (one folder per domain, imported only via its `index.ts`) → shared `components/`, `lib/`, `stores/`, `hooks/`.
Design tokens live in `src/styles/` (colours in `colors.css`, motion in `animations.css`); use their Tailwind utilities, never raw colours.
