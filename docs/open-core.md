# Cloud vs Self-Hosted

Silo is fully open-source (AGPL v3). The managed cloud version builds on the same codebase and adds convenience features for users who don't want to self-host.

## Feature Matrix

| Feature | Self-Hosted (OSS) | Cloud (Managed) |
|---------|:-----------------:|:---------------:|
| All asset/debt tracking | ✅ | ✅ |
| Auto-Pilot rules | ✅ | ✅ |
| AI insights (bring your own key) | ✅ | ✅ |
| Vault encryption | ✅ | ✅ |
| Multi-user portfolios | ✅ | ✅ |
| Export (PDF, CSV, JSON) | ✅ | ✅ |
| Fast Forward projections | ✅ | ✅ |
| Bank connections (Plaid) | ❌ | ✅ |
| Push notifications | ❌ | ✅ |
| Subscription billing | ❌ | ✅ |
| Managed hosting & backups | ❌ | ✅ |

## Why AGPL v3?

The AGPL v3 license ensures that anyone who runs Silo as a hosted service must open-source their modifications. This protects the project from being taken closed-source while keeping the full codebase available for self-hosting.
